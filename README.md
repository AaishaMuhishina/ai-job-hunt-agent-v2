# AI Job Hunt Agent 🎯

An always-on job scraping agent that finds remote AI/automation roles, scores them against my skill profile, and delivers the best matches straight to Telegram — no manual searching required.

Built for **Into the Scrape-Verse** (WeMakeDevs × Bright Data), August 2026.

---

## The problem

Job hunting on AI/automation roles means checking the same job boards over and over, scrolling past dozens of irrelevant listings to find the handful that actually match your skills. I wanted an agent that does that checking for me — automatically, every day — and only surfaces what's actually relevant.

## What it does

1. **Scrapes** RemoteOK's AI jobs page daily using a custom Bright Data Scraper Studio collector
2. **Scores** every listing against my skill profile (AI, automation, n8n, low-code) using a keyword-matching algorithm with whole-word boundaries
3. **Delivers** the top matches to Telegram automatically, and logs them to a Google Sheet
4. **Displays** the live results in a simple web dashboard

All of this runs on a schedule, unattended, via an n8n workflow.

## Best Use of Bright Data

- Built with **Scraper Studio's AI-builder** (browser UI) *and* the **Bright Data CLI** (`bdata` — via Node.js/terminal), targeting a niche category page rather than a site already in Bright Data's pre-built scraper library
- Every scrape returns structured JSON: `job_title`, `company_name`, `location`, `salary`, `tags`, `posting_date`, `apply_link`
- The Collector ID is triggered directly from an n8n workflow via `POST /dca/trigger`, turning the scraper into a production automation endpoint — no separate deployment step
- CLI commands (`bdata login`, `scraper create`, `scraper heal`, `scraper approve`) were driven through step-by-step collaboration with an AI coding assistant (Claude) — every decision, from what fields to scrape to how to phrase the self-healing prompts to how the n8n automation should be wired, was made in conversation with AI throughout the build

## Self-healing, demonstrated

**Browser UI refactor (v1 → v2):**
- v1 schema: `job_title, company_name, location, salary, tags, posting_date, apply_link`
- Plain-English request: *"Add job_type and experience_level as additional fields"*
- AI regenerated the extraction logic and schema; **same Collector ID**, output shape extended without breaking anything downstream

**CLI heal/approve cycle:**
```bash
bdata scraper heal c_mt0b62m21htptspdp6 "Also extract the salary field for each job" --url https://remoteok.com/remote-ai-jobs
# → Heal ready — awaiting approval

bdata scraper approve c_mt0b62m21htptspdp6 --url https://remoteok.com/remote-ai-jobs
# → ✓ Scraper healed: c_mt0b62m21htptspdp6
```

This is the exact loop the hackathon is testing for: describe what broke (or what's missing) in plain language, let Scraper Studio rewrite the extraction, and keep running against the same collector.

## AI matching logic

Job titles and tags are checked against a skill list (`ai`, `automation`, `n8n`, `low-code`, `workflow`, `agent`, `gpt`, `llm`, `genai`) using **word-boundary regex matching** — this was a deliberate fix after an early version matched `"ai"` inside `"Maintenance"` and returned false positives. Each match adds to a score; results are ranked and the top matches are pushed forward.

## Reliability

- Whole-word matching avoids substring false positives (see above)
- The n8n workflow includes a `Wait` node so the pipeline doesn't fetch results before the scrape finishes
- Google Sheets logging keeps a running history of every match, independent of Telegram's message limits

## AI tooling disclosure

Scraper code was AI-generated by Bright Data's Scraper Studio from plain-English field descriptions (both the initial build and the self-healing refactors). The n8n workflow logic, matching algorithm, and dashboard were built with AI coding assistance and verified/debugged manually at each step (e.g. fixing the `--url` vs `--urls` CLI flag, the substring-matching bug, and the CORS issue when live-fetching sheet data).

## Run it yourself

```bash
npm install -g @brightdata/cli
bdata login
bdata scraper run c_mt0b62m21htptspdp6 --urls https://remoteok.com/remote-ai-jobs
```

Import `n8n_workflow.json` into n8n, connect your own Bright Data, Telegram, and Google Sheets credentials, and activate the schedule.
